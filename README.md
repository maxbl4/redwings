# Протоколы гонок

Статический сайт для анализа протоколов (borisovo.club/timing): гонки, результаты гонщика, рейтинг кантри-кросса.

## Обновление данных

1. Положить новые PDF в `protocols/`.
2. `py -m pip install pymupdf` (один раз)
3. `py tools/parse_protocols.py` — пересоздаёт `site/data.js` и копирует оригиналы PDF в `site/protocols/` (ссылки на скачивание на странице гонки). Одинаковые файлы (по md5) берутся один раз.
4. `py tools/validate_data.py` — проверка результата (дырки в местах, склеенные строки и т.п.).

Поддерживается только формат borisovo.club/timing («Финишный протокол»). Старые протоколы ФМСР
«ПРОТОКОЛ ЛИЧНОГО ЗАЧЕТА» не поддерживаются — они отложены в `protocols_old_format/`.
Для отладки разметки PDF: `py tools/dump_pdf.py protocols/файл.pdf 0,1`.

Опечатки в именах исправляются словарём `tools/name_fixes.txt` («как в протоколе -> как правильно»).
Кандидатов ищет `py tools/suggest_name_fixes.py` (пары имён, отличающиеся на 1–2 буквы) — проверять вручную,
часть пар — разные люди (родственники, однофамильцы).

Гонка = дата + дисциплина (XC / MX / SS / EN). Место (`venue`) определяется по адресу: «д.Дракино» и «о.Русский» — Дракино, «д.Васильевское» — Васильевское;
в рейтинге XC по нему есть фильтр. Дата берётся из PDF, при отсутствии — из имени файла (ДДММГГ).
Гонщики между гонками сопоставляются только по «фамилия имя» (без регистра, ё = е); номер используется лишь для склейки
листов «по кругам» и «очки» внутри одного протокола.

## Просмотр

```
python -m http.server 8765 --directory site
```

и открыть http://localhost:8765. Сайт — обычные статические файлы, можно выложить на любой хостинг (GitHub Pages и т.п.).

## Рейтинг XC

log(темп гонщика в гонке) = сложность гонки − сила гонщика. Темп — средний круг без стартового и одного худшего круга.
Источник — только протоколы абсолюта (классы не учитываются). Сила оценивается робастной регрессией; сравниваются только те, кто стартовал вместе,
количество этапов и очки не влияют.
По умолчанию рейтинг считается по гонкам текущего года (если их меньше двух — текущий + прошлый), годы выбираются на странице. Проверка на прошлых данных: ~83–84% пар «кто финиширует выше» угаданы верно.

## Деплой (rw.braaap.ru)

Образ `maxbl4/rw` сам собирает `data.js` из `protocols/` (Python-стадия) и раздаёт статику через nginx.

```
docker build -t maxbl4/rw:latest .
docker push maxbl4/rw:latest
ssh root@braaap.ru "docker pull maxbl4/rw:latest && docker rm -f rw && docker run -d --name rw --restart=always -p 127.0.0.1:7001:80 maxbl4/rw:latest"
```

На сервере nginx (`/etc/nginx/sites-available/rw.braaap.ru`) проксирует https://rw.braaap.ru → 127.0.0.1:7001,
сертификат — общий `beton.braaap.ru-0002`.
